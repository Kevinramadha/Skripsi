# Rancangan Struktur PPT Sidang Baru — Tahap C dan D

Prinsip: **Tujuan → Proses → Hasil → Makna → Kesimpulan tujuan.** Metodologi tidak lagi dikumpulkan di satu bab; setiap metode langsung diikuti hasilnya. Yang tetap dibahas di depan hanya fondasi bersama (wilayah, data, kerangka 6 tahap, preprocessing) karena dipakai oleh ketiga tujuan.

Penanda prioritas presentasi:
- **[W] Wajib dijelaskan** — inti argumen; jalur minimum bila waktu sempit.
- **[S] Sebut singkat** — 15–30 detik, cukup sebut takeaway.
- **[L] Lampiran** — tidak dipresentasikan, untuk tanya jawab.

Kode slide baru: **B** = slide utama, **L** = lampiran. Kode "S" = slide PPT lama.
